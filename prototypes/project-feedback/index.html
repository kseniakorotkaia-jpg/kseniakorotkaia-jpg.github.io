Вернуть в активные
Почему отдельный справочник, а не список внутри проекта. Так делают зрелые системы (Runn, Forecast, Float, Jira): роли — общий справочник, проект их только использует. Роль в проекте — это не должность из оргструктуры: один человек может быть аналитиком на одном проекте и лидом на другом. В ресурсных системах у роли есть ещё ставка — нам она не нужна (мы не биллим), поэтому роль = название + метка + описание.
